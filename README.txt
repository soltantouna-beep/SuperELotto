SUPERELOTTO v32 PRO by P. Alaimo - PACCHETTO COMPLETO CLOUDFLARE PAGES

Questo archivio ZIP contiene TUTTI i file necessari per pubblicare
l'applicazione SuperELotto v32 Pro come Progressive Web App (PWA)
completamente autonoma e funzionante anche 100% offline.

CONTENUTO DELL'ARCHIVIO:
- index.html                (Applicazione completa con archivio storico e filtri)
- manifest.json             (Configurazione PWA per Android, Xiaomi, iOS, PC)
- sw.js                     (Service Worker nativo per funzionamento offline)
- icon.svg                  (Icona vettoriale ad alta definizione)
- pwa-192x192.png           (Icona homescreen Android / PWA)
- pwa-512x512.png           (Icona splash screen alta risoluzione)
- pwa-maskable-512x512.png  (Icona adattiva per launcher moderni)
- favicon.png               (Icona per scheda del browser)
- apple-touch-icon.png      (Icona per dispositivi Apple iOS / iPadOS)
- _headers                  (Configurazione ottimizzata intestazioni Cloudflare)
- README.txt                (Questa guida)

COME PUBBLICARE SU CLOUDFLARE PAGES IN 30 SECONDI:
1. Accedi alla tua Cloudflare Dashboard (https://dash.cloudflare.com).
2. Vai su "Workers & Pages" -> clicca "Create application" -> "Pages".
3. Seleziona la scheda "Upload assets".
4. Scegli il nome del tuo progetto (es. "superelotto").
5. Trascina direttamente questo file ZIP oppure la cartella con i file estratti.
6. Clicca "Deploy site". L'app sarà online al tuo URL personale https://superelotto.pages.dev!
